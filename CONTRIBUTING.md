## 1. Accès Collaborateur gratuit

Le business plan prévoit un **Accès Collaborateur à 0 €** pour les étudiants et chercheurs qui soumettent une **Pull Request validée et mergée**.

Conditions cumulatives :

1. La PR est mergée dans `main`.
2. La PR corrige un problème réel ou ajoute une fonctionnalité utile, testée et documentée.
3. Chaque commit contient un sign-off DCO : `git commit -s`.
4. La PR respecte `SECURITY.md`.
5. La PR ne contient aucun secret, clé API, token, donnée personnelle ou exploit public.
6. Un mainteneur ajoute ensuite le compte GitHub à la liste d’accès Collaborateur.

L’accès est nominatif, non transférable, et peut être révoqué en cas d’abus.  
Aucun document d’identité n’est demandé. L’affiliation étudiant/chercheur est déclarative.
